# Emrecan Gulay Research Portfolio

Static research portfolio for applied research, UX research, responsible AI, human AI interaction, and academic roles. The site presents one trajectory across feedback oriented design inquiry, HMI technology planning, Relational Dissonance, and the accepted NordiCHI 2026 Relational Transparency demo.

Live site: https://emrecan713.github.io/research-portfolio/

## Local preview

Run `start.bat`, then open http://127.0.0.1:8768/.

## Structure

* `index.html` contains the semantic page content.
* `css/style.css` contains the responsive and print styles.
* `js/main.js` contains progressive enhancement for navigation and reveal motion.
* `assets/images` contains compressed portfolio images.
* `assets/media` contains the 55 second prototype demo.
* `assets/documents` contains the downloadable portfolio PDF.

The site uses relative paths and can be published directly from the repository root with GitHub Pages.
